About

Passionate about web development, I build modern, high-performing, and user-centered web applications with a strong focus on responsive design and seamless user experiences.

Professionally trained in Front-End Development, I have expanded my skills into back-end development and now build full-stack applications using the MERN Stack: MongoDB, Express, React, and Node.js.

I enjoy working across the entire development process, from designing responsive interfaces and building reusable React components to developing REST APIs, managing databases, and connecting front-end applications to the back end.
